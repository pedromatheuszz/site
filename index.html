Sobre

Sou desenvolvedor com formação em múltiplas linguagens e um interesse particular por resolver o problema certo — não apenas escrever código que compila.

Minha atuação cobre as duas pontas do produto. No front-end, construo interfaces em React e TypeScript com atenção a performance, acessibilidade e detalhe visual. No back-end, trabalho com Python, Java e C# para modelar domínios, expor APIs consistentes e manter o sistema previsível conforme ele cresce.

A formação em linguagens de mais baixo nível, como C++, moldou a forma como penso desempenho, memória e estruturas de dados — e isso aparece mesmo quando o projeto é uma aplicação web. Gosto de código legível, testado e que a próxima pessoa consiga manter sem arqueologia.

Processo

  1. Etapa 01

    Entender

    Conversa inicial para mapear o problema, os usuários e o que define sucesso. Sem isso, o resto é chute.

  2. Etapa 02

    Planejar

    Escopo, arquitetura e prioridades definidos por escrito. Você sabe o que vem, quando vem e por quanto.

  3. Etapa 03

    Construir

    Entregas incrementais com código versionado e testado. Você acompanha o progresso, não só o resultado final.

  4. Etapa 04

    Entregar

    Deploy, documentação e transferência de conhecimento. O projeto fica funcionando — e possível de manter.
